        🧠 AI Tools
        
      

      

        
Operates on the active project (none). Launch a project from the Projects tab first.


        

          Inventory
          

            
Scans the project for AI models, required API keys, config files, and guardrail files in use.

            
            
—

          

        


        

          Metrics
          

            
Real recorded AI call latency/cost/error data for this project (nothing here until something records an event via aiFwRecordMetric).

            
            
—

          

        


        

          Guardrail Testing
          

            
Runs every npm script whose name matches guardrail/contract/safety/compliance/constitution and reports real pass/fail.

            
            
—

          

        


        

          Guarded Upgrade
          

            
Backs up a config file, does a literal find/replace, then keeps the change only if guardrail tests and lint still pass - otherwise rolls back automatically.

            

            

            

            
            
—

          

        


        

          Prompt Testing
          

            
Save named prompt variants and record quality scores against them (score comes from you or your own eval script).

            

            
            
            

              
              
              
            

            
            
—

          

        


        

          Dependency Audit
          

            
Checks installed vs. latest version for AI-related npm packages (Gemini, Anthropic, OpenAI, Firebase, etc). Latest-version lookups are best-effort and skipped gracefully offline.

            
            
—

          

        


        

          Compliance
          

            
Latest guardrail score, trend vs. the previous run, and any manually-logged violations.

            
            
—

          

        


        

          AI Changelog
          

            
Filters this project's real git history down to commits that touch AI-related files or mention AI-related terms.

            
            
—

          

        


        

          Knowledge Base
          

            
Cross-project notes on what worked - carries lessons forward into the next project, not just this one.

            

            
            
            
            
—

          

        


        

          Model Training
          

            
Nexus collects an example only after a generated change passes real project guardrails. Credentials and personal paths are removed before the example is stored. Ten verified examples are required before training.

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
              
            

            
No training dataset prepared yet.

          

        


        

          Experiments
          

            
Side-by-side comparison of two variants (models, prompts, whatever) using real recorded numeric observations.

            

              
              
              
            

            
            

              
              
              
              
            

            

              
              
            

            
—

          

        


        

          Recommendations
          

            
Concrete suggestions derived from real thresholds on already-recorded metrics, compliance, and dependency data - never invented.

            
            
—

          

        


        

          Trend Alerts
          

            
Compares the most recent 10 recorded calls per model against the 10 before that - flags a real drop in success rate or jump in latency. Not a prediction, just real-number arithmetic.

            
            
—

          

        


        

          Cost Optimizer
          

            
Set your own known price per model (from the provider's pricing page - Nexus never guesses this), then see real cost from real recorded token usage.

            

              
              
              
              
            

            
            
—

          

        


        

          Performance Tuner
          

            
Real p50/p90 latency per model from actually recorded calls, and which reliable (≥90% success) model is currently fastest.
